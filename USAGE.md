## How To Use?

### FriendFix
- On the Add Friend screen, you can add a friend.
- without #, request will send without #
- with #, request will send with # (like old name system)

### ThreadCMD
- If you want to make thread, use /thread {name} command
- surprisingly, this is one of backports of RN

### ForumTagFix
- If there are tags for that forum channel, when you write post, tag selector will be displayed.
- If there aren't tags, tag selector will not be displayed.
- If you want to change tags of that post, then you should long press that on post list screen  
(There will be an 'Edit Tag' in the menu.)

### ThreadDEL
- It makes you can delete threads or channels on list screen
- just long press what you want to delete
- If you want change button's text, go to plugin setting

### MediaChannelFix
- You don't have to do anything.

### HeicFix
- If image cache is so big, just restart app  
(this remove caches on start)

### CopyBackTick
- You don't have to do anything.
- Want copy? click to backtick
- surprisingly, this is one of backports of RN

### FileNameFix
- You don't have to do anything.

### EmojiRank (Deprecated)
- You don't have to do anything.
- this will change 'Recent' sections on emoji selector
- if you did not want that, just turn off this plugin

### FixOnboardingFork
- this fork? of FixOnboarding plugin (but in fact, it was implemented completely differently)
- If you join server and message is not sent, use /onboarding command
- /onboarding command will display simple onboarding dialog
- not supporting to change onboarding answers you did on past
- Added from 1.1.1, You can onboarding on guild menu, which display when long-press guild icon.

### MosaicFork
- You don't have to do anything.
